## ⚡ 什么是 Silvirica AI？

Silvirica AI **不是** 又一个底层基座模型。

Silvirica AI 是部署在 **IDE / AI 编程助手**（如 Cursor、Antigravity IDE、Claude Desktop、VS Code）与 **AI 大模型** 之间的**智能运行层**。它彻底消除全量代码盲目填充带来的 Token 膨胀，通过 **零 Token 快速网关** 在 40ms 内解决确定性问题，依托 AST 精准提取符号与代码片段，维护基于 Obsidian 双链的持久化项目记忆，并按需渐进式加载 142 项专业技能。

## 💎 核心优势

1. **⚡ 极致 Token 节约（约 99% 节省）**:
   - 杜绝整库文件盲目投喂，通过 AST 多语言解析器精准提取类与函数。
   - 确定性符号查找与架构查询走 **零模型路径（0 Token，<40ms）**。
2. **🧠 真正的持久化 Obsidian 项目记忆**:
   - Markdown 原生存储，支持 `[[双向链接]]`、标签、架构决策记录 (ADR) 与历史 Bug 防范记忆。
3. **🕸️ SQLite 驱动的精准知识图谱**:
   - 毫秒级多跳调用链、依赖关系、路由和数据库表追踪。
4. **🛡️ 防御性安全与敏感信息自动脱敏**:
   - 自动识别 API 密钥、密码与漏洞模式，防止敏感代码泄漏到云端模型。
5. **🎯 142 项渐进式技能体系**:
   - 采用 3 级渐进加载（Level 0 元数据 → Level 1 摘要 → Level 2 完整指令），零多余负载。
