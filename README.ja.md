## ⚡ Silvirica AIとは？

Silvirica AIは単なる新しい基盤モデルではありません。

IDE / AIコーディングアシスタント（Cursor、Antigravity IDE、Claude Desktop、VS Code）と基盤モデルの間に常駐する**インテリジェント・オペレーティング・ランタイム**です。コードベース全体の盲目的なプロンプト肥大化を排除し、決定論的に解けるクエリを**0トークン・40ms未満**で即座に解決し、必要なシンボルのみをAST解析で外科的に抽出し、Obsidian形式のマークダウン記憶と142の特化スキルを動的に提供します。

## 💎 主な特徴

1. **⚡ 圧倒的なトークン削減（約99%削減）**:
   - リポジトリ全体の丸投げを防止し、ASTによるシンボル単位の抽出を実行。
   - 決定論的なシンボル・ルーティング・git照会を**ゼロモデル実行（0トークン）**で即答。
2. **🧠 永続的なObsidian形式のプロジェクトメモリ**:
   - `[[内部リンク]]`やタグに対応したマークダウン形式で設計決定（ADR）や過去のバグ修正記憶を管理。
3. **🕸️ SQLite ナレッジグラフ**:
   - 呼び出し関係、依存関係、ルート、DBテーブル、テストの関係性を数ミリ秒でマルチホップ追跡。
4. **🛡️ 防御的セキュリティ & 秘密情報の自動マスキング**:
   - APIキーやパスワードが外部LLMに送信される前にローカルで自動検知・マスキング。
5. **🎯 142の段階的スキルロード**:
   - 必要な時だけレベル0（メタデータ）→ レベル1（要約）→ レベル2（詳細指示）と展開。
