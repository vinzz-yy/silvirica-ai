# Silvirica Skill Catalog Index

Generated shortlist surface: every routable Silvirica skill's name and one-line description, regenerated from the catalog on every `Silvirica setup`/`Silvirica update`. Shortlist candidate workflows here first; `Silvirica recommend "<request>" --json --limit 3` stays authoritative for confirmation and policy metadata (next action, evidence boundary). Never paste full catalog dumps into chat context.

Trigger phrases and the role registry live in `references/workflow-registry.md`; descriptions stay in this separate file because merging both registries would breach the per-reference byte budget.
