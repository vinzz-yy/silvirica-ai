## ⚡ Silvirica AI란 무엇인가요?

Silvirica AI는 또 다른 거대 언어 모델이 아닙니다.

IDE / AI 코딩 어시스턴트(Cursor, Antigravity IDE, Claude Desktop, VS Code)와 AI 기반 모델 사이에 위치하는 **지능형 운영 런타임**입니다. 프로젝트 전체 파일을 불필요하게 프롬프트에 넣는 낭비를 제거하고, 결정론적 질의는 **0토큰 및 40ms 미만**으로 해결하며, AST 기반 심볼 추출, Obsidian 마크다운 메모리, 142개 전문 스킬을 실시간으로 연계합니다.

## 💎 핵심 기능

1. **⚡ 혁신적인 토큰 절감 (~99% 절약)**:
   - 전체 코드 덤프 대신 필요한 클래스/함수만 AST 기반으로 추출.
   - 제로 모델 경로(Zero-Model Path)를 통해 0토큰으로 로컬 심볼 및 스택 질의 즉각 응답.
2. **🧠 영구적인 Obsidian 스타일 마크다운 메모리**:
   - `[[위키링크]]`와 태그를 지원하는 설계 결정(ADR) 및 버그 재발 방지 실패 메모리 보관.
3. **🕸️ SQLite 기반 지식 그래프**:
   - 심볼 간 호출 관계, 라우트, DB 테이블, 테스트 간 다중 홉 종속성 분석.
4. **🛡️ 보안 강화 및 민감 정보 자동 마스킹**:
   - API 키, 시크릿 정보가 외부 AI로 전송되기 전 로컬에서 완벽 차단 및 마스킹.
5. **🎯 142개 단계별 스킬 시스템**:
   - Level 0 (메타데이터) → Level 1 (요약) → Level 2 (전체 지침) 단계적 프롬프트 로딩.
