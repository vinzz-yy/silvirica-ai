# Project: silvirica ai

## Overview
Silvirica AI is an open-source, vendor-agnostic AI Intelligence Optimization Layer designed to make AI coding assistants faster, cheaper, memory-aware, security-aware, and token-efficient across all major IDEs and model providers.

## Technology Stack
- **Primary Language**: Python 3.9+
- **Database / Graph Engine**: SQLite 3 (Knowledge Graph, Symbol Index, Telemetry Store)
- **Protocols**: Model Context Protocol (MCP stdio/JSON-RPC), CLI, HTTP REST Daemon
- **Dependencies**: `pyyaml`, `requests`
- **Supported Ecosystems**: Python, JavaScript/TypeScript, React/Next.js, PHP/Laravel, Go, Rust, Java/Spring, C#/.NET, SQL
